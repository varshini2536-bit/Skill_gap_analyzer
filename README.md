# Skill_gap_analyzer
Analyze skill gap between candidate And job requirements 
Overview 
This project analyzes the gap between a candidate’s skills and job requirements using Python. It helps identify matched skills, missing skills, and calculates the overall match percentage. The goal is to guide users in improving their job readiness by focusing on required skills.
Tools used
*Python
*Data Structures (List, Set)
*Matplotlib (for visualization)
Key Insights
•Skill gap analysis helps identify missing skills required for a job
•Match percentage provides a quick understanding of job readiness
•Visualization makes it easy to compare matched vs missing skills
•Improving missing skills increases chances of getting hired
•Data-driven approach helps in better career planning
